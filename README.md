Entry for the make.fun competition
`u-mang-the-moon-finally-answers-back-781a7ec1`.

`main.ts` writes a single one-line reply from the Moon — what the Moon says
when it finally answers back — to `/output/entry.txt`. The line is validated
before it is written: 1 to 240 characters, a single line, not only white
space.

The entry line:

> The Moon finally answered back: it has been trying to reach us about Earth's extended warranty, and the offer expires at midnight.
